## 적용 규칙

| 역할 | 색상 | 적용 |
| --- | --- | --- |
| 학교 배너 | `#004094` | 맨 하단 학교 배너에만 사용 |
| 행동 | `#292A2C` | 분석 시작·질문 보내기 버튼, 입력 화면의 실행 영역 |
| 강조 | `#FBD512` | AI 진단 패널의 상단선 |
| 선택·강조 | `#FFF8D8` / `#F8EAB0` | 호버·선택 / 키보드 포커스 표시 |
| 입력 영역 | 흰색 / `#DEDED9` | 분석 파일·분석 조건 카드의 배경 / 테두리 |
| 작업 면 | 흰색 / `#F4F4F2` | 카드 / 페이지 배경 |
| 본문 | `#24272B` / `#646C76` | 주요 내용 / 보조 설명 |

화면 테마는 노랑·차콜과 중립 회색으로 통일하며, 파랑은 학교 배너에만 사용합니다.
상단 소개 박스와 탐색 메뉴, 사용 안내 팝업은 제거했습니다.
노란색은 강조에, 차콜은 제목·아이콘·버튼·체크박스에 사용합니다.
비활성 버튼은 회색으로 표시하며, 안전·경고·위험의 의미를 나타내는 색은 별도로 유지합니다.
학교 로고와 길바닥연구소 로고의 원본 색상과 비율은 그대로 사용합니다.
